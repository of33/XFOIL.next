# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

XFOIL.next does not currently publish a dedicated private security contact
address. Until one is published, report a suspected vulnerability through a
private channel on the project hosting page
(https://github.com/of33/XFOIL.next), for example a private security
advisory, rather than in a public issue. The absence of a dedicated security
contact is a known open release point and may be addressed in a future
release.

Do not include credentials, tokens, or other secrets in a report.

## Supported versions

Security fixes are tracked for the current release line, initially `1.0.x`.
Older release lines are not separately supported until they exist.

## Scope and expectations

XFOIL.next is a numerical aerodynamics tool. Its numerical validation
against the Fortran reference demonstrates numerical agreement, not
security. Numerical validation is not a security guarantee.

No response or fix time is promised. Reports are reviewed as they arrive.
