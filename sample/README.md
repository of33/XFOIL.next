# Sample airfoil profiles

This directory contains two example airfoil coordinate files used as user
examples and as native batch-mode golden inputs. They are plain coordinate
data; there is no profile-specific production code in this project.

## CLARK_Y.dat

- Format: XFOIL DAT file. One header line (`CLARK Y`) followed by
  whitespace-separated `x  y` coordinate pairs (2 columns).
- Coordinate points: 151.
- SHA-256: `4726e211c8931868f7e1bac5e16e5d674727d4e7af231a28c2af9ac629d380ae`
- Provenance: the classic Clark Y cambered airfoil. This file is **not**
  present in the XFOIL 6.99 upstream distribution
  (`xfoil6.99.tgz`); it is provided by the project owner. The exact
  coordinate source is not pinned to a specific upstream file, so it is
  recorded as an open provenance point (see `NOTICE`). It is retained as a
  well-known textbook profile.
- Use: user example and native batch golden case G1
  (`tests/golden/batch/clark_y.xfb`).

## NACA2312.dat

- Format: one header line (`NACA 2312`) followed by 255 rows of three
  whitespace-separated columns in scientific notation. The project's DAT
  reader (`src/app/DatFileReader.cpp`, `parseTwoNumbers`) consumes only the
  first two columns as `x  y`; the third column is ignored on load.
- Coordinate points: 255.
- SHA-256: `03a7f14c6226b5cf75b2884ff90c1b87513fe433e38ba26a79e4465257f39e8c`
- Provenance: provided by the project owner (2026-10-31). It is **not**
  present in the XFOIL 6.99 upstream distribution. It is not byte-identical
  to, and does not use the same discretization as, the canonical Fortran
  NACA-2312 generator output (`fortran-bin/xfoil`, `NACA 2312` + `SAVE`
  produces a 160-point, 2-column file). Its trailing-edge coordinate
  magnitudes are consistent with the canonical NACA 2312 thickness at the
  trailing edge, but the file cannot be data-based-proven to originate from
  the canonical NACA generator. It is therefore classified as a
  project-owner-provided sample.
- Use: user example and native batch golden case G2
  (`tests/golden/batch/naca2312.xfb`).

## Internal NACA cases

The internal NACA golden cases 4415 and 0012 are generated by the project's
own NACA routine (a direct port of `fortran-src/xfoil-6.99/naca.f`) and need no sample
coordinate file in this directory.
